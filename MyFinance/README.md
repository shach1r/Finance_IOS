# Мои Финансы (iOS)

Приложение для учёта личных финансов на SwiftUI. Операции по категориям,
месячные лимиты, цели накопления с прогнозом срока и отчёты по месяцам.
Данные хранятся локально на устройстве.

## Экраны

- **Главная** — баланс, доходы и расходы за месяц, статус лимитов по категориям
  (зелёный до 80 %, жёлтый на подходе, красный при перерасходе).
- **Операции** — список за месяц по дням, добавление через шторку, удаление свайпом.
- **Отчёт** — доли расходов по категориям и динамика доход/расход за полгода.
- **Цели** — прогресс, прогноз срока по текущему темпу сбережений, пополнение.
- **Настройки** — тема, стартовый баланс, управление категориями.

## Как устроено

Архитектура MVVM с единым источником правды.

```
Models.swift            структуры данных: Category, Transaction, Goal, Settings
Defaults.swift          категории и цели по умолчанию для первого запуска
LocalStore.swift        хранилище на JSON-файлах в Documents (load / save)
AppState.swift          ViewModel: данные + производные величины + сохранение
Format.swift            форматирование денег и дат
MyFinanceApp.swift      точка входа, создаёт AppState и задаёт тему
RootView.swift          пять вкладок
HomeView / TransactionsView / AddTransactionSheet
ReportView / GoalsView / SettingsView
```

Экраны не знают, где лежат данные. Они читают `AppState` и вызывают его методы;
`AppState` пишет изменения в `LocalStore`. Чтобы добавить синхронизацию с сервером,
достаточно завести вторую реализацию хранилища с тем же интерфейсом load/save —
экраны трогать не нужно.

Состояние меняется заменой элементов, а не правкой на месте
(`goals[i] = updated`, а не `goal.saved += ...`), чтобы SwiftUI гарантированно
замечал изменение и перерисовывал список.

## Требования

- iOS 16.0+
- Xcode 15+

## Запуск

Создать проект в Xcode (App, SwiftUI), добавить файлы из этой папки, выбрать
симулятор iPhone и нажать Run. Подробности — в комментариях к коду.
